# Tree Sterility Classification Using Machine Learning

Eii project-e Tree Sterility Dataset niye exploratory data analysis (EDA), data preprocessing ebong baseline machine learning classification workflow toiri kora hoyeche.

## 📌 Project Overview
- **Dataset Size:** 2,783 rows × 24 columns
- **Domain:** Ecological, Soil & Tree Sterility Analysis
- **Key Features:** Environmental metrics (Light_ISF, AMF, EMF, Phenolics, Lignin, NSC) ebong categorical attributes (Species, Soil, Sterile status, etc.)
- **Problem Type:** Supervised Machine Learning (Classification)

## 🛠️️ Tech Stack & Libraries
- **Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Machine Learning:** Scikit-Learn, TensorFlow

## 📊 Workflow & Analysis Done
1. **Data Preprocessing:** Missing values check, data types inspect kora ebong drive theke dataset download/load kora.
2. **Exploratory Data Analysis (EDA):**
   - Summary statistics (Mean, Standard Deviation, Variance, Min, Max).
   - Categorical feature analysis o unique values count.
   - Numerical distribution visualization (Histograms, Box Plots, KDE).
   - Correlation Heatmap analysis.
3. **Model Preparation (Imported):**
   - K-Nearest Neighbors (KNN)
   - Decision Tree Classifier
   - Logistic Regression
   - Multi-Layer Perceptron (MLP) Neural Network
